# Shanghai Roulette

A place randomiser for filming in Shanghai. Tap once and it eliminates every
eligible venue in the city down to one, on a star chart drawn from real
OpenStreetMap geometry.

**Open it on an iPad, then Share → Add to Home Screen.** The first load copies
the whole app — all 2.5 MB of map data — onto the device. After that it runs
entirely offline: no network calls, no map tile servers, nothing to reach.
That matters because it is used on the street in Shanghai, where most western
hosting is unreachable.

`check.html` reports whether the device can run it, and whether an offline
copy has been stored.
